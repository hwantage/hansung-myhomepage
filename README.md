## 실행

프로젝트 폴더에서 다음 명령으로 실행합니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:4173 에 접속합니다. ES 모듈을 사용하므로 HTML 파일을 직접 더블클릭하는 대신 HTTP 서버로 열어야 합니다. 별도 빌드나 패키지 설치는 필요하지 않습니다.

## 구성

- `index.html`: 자기소개, 기술 스택, 프로필, FAQ와 연락처.
- `style.css`: 레퍼런스를 재해석한 색상, 타이포그래피, 반응형 구성.
- `studio.js`: 실제 3D 작업실, 스크롤 카메라, 드래그, 기기 클릭과 화면 전환.
- `journey.js`: 8개 구간의 카메라 경로, 기기별 화면 크기와 구간 설명.
- `assets/`: 작업실에서 캡처한 프로필 사진과 WebGL 대체 이미지.
- `vendor/`: 로컬에 포함한 Three.js 0.180.0과 MIT 라이선스.
- `artifacts/design-qa/`: 브라우저 캡처, 레퍼런스 비교와 검증 결과.
- `design-qa.md`: 디자인 검수 기록.

## 작업실 둘러보기

스크롤하면 작업실 전체에서 줌인하고 **랜선 허브 → PC 뒤쪽 랜 포트 → 키보드 → 마우스 → 헤드폰 → 스피커 → 모니터 → 연결된 작업실**로 이동합니다. 데스크톱에서는 약 10.5화면, 모바일에서는 약 9.5화면 길이의 이동입니다. 신호를 나타내는 파란 연결선이 스크롤에 맞춰 켜지고, 오디오 기기 주변에서 곡선을 그린 뒤 모니터에서 다른 오브제로 퍼집니다. 마지막에는 전체 작업실을 다시 보여줍니다.

하단의 8개 구간 버튼은 원하는 기기로 바로 이동합니다. **Skip to about**으로 긴 둘러보기를 건너뛸 수 있습니다. 처음 전체 작업실을 보는 시점에서는 마우스로 드래그해 둘러볼 수 있습니다. 가까운 구간에서는 카메라가 정해진 경로를 따라가며 마우스에 가볍게 반응합니다. 모니터, 키보드, 마우스를 클릭하거나 **화면 바꾸기** 버튼을 누르면 모니터의 Build / Design / Ship 화면이 전환됩니다. **움직임 멈춤** 버튼은 카메라, 신호와 화면 확장을 함께 정지하고, 재생하면 현재 스크롤 위치까지 부드럽게 이동합니다.

초반 확대는 고정된 전체 화면 캔버스 안에서 카메라의 투영 영역을 바꾸는 방식입니다. 스크롤할 때 WebGL 버퍼 크기를 다시 설정하지 않습니다. 카메라만 이동하는 동안 그림자를 재사용하고, 키캡·포트 핀·통풍구 등 반복되는 형상은 GPU 인스턴싱으로 함께 그립니다. 제목, 구간 설명과 카메라는 같은 보간된 스크롤 값을 사용합니다.

OS의 움직임 줄이기 설정에서는 정지된 장면을 표시하며 긴 스크롤 연출을 생략합니다. WebGL을 사용할 수 없거나 그래픽 컨텍스트를 잃으면 작업실 이미지로 대체합니다. 장면이 화면 밖에 있거나 탭이 비활성화되면 렌더링을 멈추고, 입력이 없는 상태에서는 반복 렌더링하지 않습니다.

폰트는 Google Fonts의 Manrope와 Noto Sans KR을 사용합니다. 폰트를 불러올 수 없는 환경에서는 시스템 sans-serif로 표시합니다. 3D 코드와 작업실 이미지는 외부 CDN에 의존하지 않습니다.

Reference: [Vectr](https://www.vectrfl.com/). Rendering: [Three.js](https://threejs.org/).

## 스크롤 회귀 검증

로컬 서버가 실행 중이고 Python Playwright와 Chromium이 설치되어 있다면 다음 명령으로 검증합니다.

```sh
python3 scripts/verify_scroll_rendering.py
```

초반 스크롤 중 캔버스 재설정, 그림자 재계산, 정지 후 불필요한 렌더링, 후면 포트 연결과 카메라 방향, 확대 중 멈춤/재생, 실제 뷰포트 크기 변경을 데스크톱과 모바일 해상도에서 확인합니다. 결과는 `artifacts/design-qa/scroll-fix/verification.json`에 저장됩니다. 소프트웨어 WebGL 측정값은 실제 기기의 FPS를 의미하지 않습니다.
