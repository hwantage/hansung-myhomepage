# Hwantage's workspace

김정환의 개인 홈페이지. Vectr의 밝은 공간감과 스크롤을 따라 움직이는 3D 연출을 개인 개발 작업실로 해석했습니다.

## 실행

프로젝트 폴더에서 다음 명령으로 실행합니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:4173 에 접속합니다. ES 모듈을 사용하므로 HTML 파일을 직접 더블클릭하는 대신 HTTP 서버로 열어야 합니다. 별도 빌드나 패키지 설치는 필요하지 않습니다.

## 구성

- `index.html`: 자기소개, 기술 스택, 프로필, FAQ와 연락처.
- `style.css`: 레퍼런스를 재해석한 색상, 타이포그래피, 반응형 구성.
- `studio.js`: 실제 3D 작업실, 스크롤 카메라, 드래그, 기기 클릭과 화면 전환.
- `assets/`: 작업실에서 캡처한 프로필 사진과 WebGL 대체 이미지.
- `vendor/`: 로컬에 포함한 Three.js 0.180.0과 MIT 라이선스.
- `artifacts/design-qa/`: 브라우저 캡처, 레퍼런스 비교와 검증 결과.
- `design-qa.md`: 디자인 검수 기록.

## 작업실 둘러보기

스크롤하면 책상 전체를 보는 시점에서 기기에 가까이 다가갑니다. 마우스로 드래그해 시점을 돌릴 수 있습니다. 모니터, 키보드, 마우스를 클릭하거나 **화면 바꾸기** 버튼을 누르면 모니터의 Build / Design / Ship 화면이 전환됩니다. **움직임 멈춤** 버튼으로 시점 이동을 정지할 수 있습니다.

OS의 움직임 줄이기 설정에서는 정지된 장면을 표시하며 긴 스크롤 연출을 생략합니다. WebGL을 사용할 수 없거나 그래픽 컨텍스트를 잃으면 작업실 이미지로 대체합니다. 장면이 화면 밖에 있거나 탭이 비활성화되면 렌더링을 멈추고, 입력이 없는 상태에서는 반복 렌더링하지 않습니다.

폰트는 Google Fonts의 Manrope와 Noto Sans KR을 사용합니다. 폰트를 불러올 수 없는 환경에서는 시스템 sans-serif로 표시합니다. 3D 코드와 작업실 이미지는 외부 CDN에 의존하지 않습니다.
